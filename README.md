# 🎓 AI Study Assistant

A responsive study dashboard that helps students organize notes, plan study tasks, and track their progress.

🔗 **Live Demo:** https://akshaysharma17638-alt.github.io/ai-study-assistant/

![Dashboard](screenshots/dashboard.png)

## ✨ Features

- 📝 **My Notes:** add and delete notes, saved in LocalStorage
- 📅 **Study Planner:** add, complete, and delete tasks
- 📈 **Progress Tracker:** total, completed, and pending tasks with a live percentage
- 💬 **Study Chat:** chat interface with clearly labeled demo responses
- 🗓️ Today's date and a personalized welcome message
- 📱 Responsive design for desktop, tablet, and mobile

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, event listeners)
- LocalStorage

## 🚀 How to Run Locally

1. Clone the repository:
   git clone https://github.com/akshaysharma17638-alt/ai-study-assistant.git
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**
